# منصة «نِعمة» لحفظ النعمة والحد من هدر الطعام (`E:\hefz-alnaema`)

تطبيق ويب متجاوب يعمل بنظام **النموذج الهجين الشامل** لربط الأطراف الثلاثة (المُزوّد، المستفيد/الجمعيات، والمندوب/المتطوع) مع منظومة متكاملة للسلامة الغذائية وقياس الأثر البيئي والاجتماعي.

## المسارات الأربعة المدعومة في التطبيق
1. **النموذج الخيري (تبرع مجاني):** ربط قاعات المناسبات والفنادق والمطاعم بالجمعيات الخيرية والمتطوعين.
2. **النموذج التجاري الاجتماعي (خصم 50% - 70%):** بيع فائض المخابز والمطاعم اليومي بأسعار مخفضة (بوكس المفاجآت).
3. **النموذج المجتمعي (بين الجيران Peer-to-Peer):** مشاركة الفائض المنزلي بين سكان الحي الواحد مجاناً.
4. **مسار صفر هدر (Zero Waste):** توجيه بقايا الطعام غير الصالح للاستهلاك الآدمي إلى مصانع الأسمدة العضوية ومزارع الحيوانات.

## الميزات المدمجة
- **رادار الموقع الجغرافي (GPS Radar):** عرض الفوائض القريبة حسب المسافة لتفادي تلف الطعام أثناء النقل.
- **عداد الصلاحية الذكي وتصنيف الحرارة:** تصنيف كل شحنة (`ساخن > 60°C`، `مبرد 4°C`، `جاف`) مع عداد تنازلي حي.
- **توثيق الاستلام المرن (بأي وسيلة واحدة تكفي):** إتاحة 3 خيارات مرنة للمندوب والمستفيد لتأكيد التسليم (إما عبر كود `PIN / QR Code`، أو التسليم اللا تلامسي عند الباب مع مطابقة `GPS` حفظاً لكرامة الأسر المتعففة، أو التأكيد المباشر من جوال المستفيد) بحيث تكفي أي وسيلة واحدة منها لإتمام التوثيق.
- **حاسبة التنبؤ الذكي بالفائض للمناسبات:** أداة لمساعدة قاعات الأفراح والفنادق على تقدير الفائض المتوقع وحجز الجمعيات والمناديب مسبقاً.
- **لوحة الأثر والأوسمة (Gamification):** حساب الوجبات المُنقاذة، خفض الانبعاثات الكربونية (`CO₂`)، النقاط، وإصدار شهادات شكر رقمية.
